## Aim: strictly beyond the public0.95540 plateau

Our v38 and [goodpjw2008 Step Q](https://www.kaggle.com/code/goodpjw2008/s6e11-board-model-realmlp-lb-0-95540) both display0.95540. A tie is not a successful experiment in this round.

The public observation bank has expanded from41 to70 distinct rankings. Original artifacts are marked separately from recipe reconstructions. Several rebuilt chains match original SHA or ranks; some intermediate rank averages vary in their last bits across platforms. Those reconstructed observations retain explicit extra variance and are never claimed to be the original scored bytes. A second fit uses only original artifacts as a sensitivity check.

The forecasting model now scales its approximation noise with squared rank distance from the measured reference. This stops a nearby measured tie from receiving the same error allowance as a much older, different file. The physical public-subsample covariance p(1-sp)/s is primary. Its forward error was smaller than the source-style covariance on both full and original-only histories. The original conservative all-profiles gate selected nothing. We explicitly amended the PUBLIC search protocol before sending anything: physical scaling is primary, and source-style scaling remains a sensitivity check. This is an adaptive public decision, not independent proof.

The candidate uses both public-scored directions and152 publicly available member predictions. Coefficients and exact arrays are frozen below; 149 of the members also have supplied public OOF. The runtime uses only test-side arrays, with input hashes and IDs checked. It keeps the existing four public low-risk regions. Broader risk frontiers were rejected because held-out frauds were demoted. A prior calibrated from the public wide-stack OOF did not improve historical forecasting and is not used.

Optional diagnostics refit all four forecast profiles from the exact published matrices. Default execution replays the frozen inference recipe. This is selected on public score history; hidden-private quality is unknown. Our private own model and its data remain separate. Every scored trial is a new executed PUBLIC version of this same notebook, with no private screening or standalone CSV competition uploads. At most three submissions in this round, preserving at least four for later.
